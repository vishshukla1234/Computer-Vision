# 🖱️ Virtual Mouse Assistance using OpenCV & MediaPipe

This project implements a **Virtual Mouse** that allows users to control the computer cursor using **hand gestures** detected through a webcam.  
It uses **OpenCV**, **MediaPipe**, and **AutoPy** to track hand movements and perform mouse operations such as **movement** and **clicking**.

---

## 🚀 Features
- 🖐️ Real-time hand tracking using **MediaPipe**
- 🎯 Control mouse movement using your **index finger**
- 👆 Perform mouse **clicks** by bringing your **index and middle fingers** close together
- 🧭 Smooth cursor motion using coordinate interpolation
- 💻 Works seamlessly with any standard webcam

---

## 🧰 Technologies Used
- **Python 3.x**
- **OpenCV** – for video capture and image processing  
- **MediaPipe** – for hand landmarks detection  
- **AutoPy** – for controlling mouse actions  
- **NumPy** – for mathematical operations
